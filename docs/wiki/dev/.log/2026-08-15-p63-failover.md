# ingest — P6.3: failover topology (2026-08-15)

**Shipped:** the pull-on-promote / push-per-round failover for `GitStore` — Gap 2 (the High
"node-independence broken" finding) closed. `WikiStore` gains `refresh()`/`publish()` as **default
no-op methods** (additive; Fs/S3 inherently shared → nothing changes). `GitStore` with a configured
`remote`: refresh = ls-remote (an empty origin is a valid fresh start) + fetch + **adopt the remote
head** + best-effort worktree restore; publish = push with a **worktree-free plumbing merge retry**
(`merge-tree --write-tree` + two-parent `commit-tree` — disjoint council subtrees merge cleanly, a
genuine same-path conflict surfaces; needs git ≥2.38) + the post-push ls-remote **divergence
tripwire** (`push_divergences()`, counted + warned, never auto-fixed — ported from GitMirror).

**Curator wiring:** `become_curator` refreshes **before serving** and a failure REFUSES the
curatorship (a knowingly-stale curator is the data-loss path; the node re-arms the reader watch);
the drain loop publishes best-effort after each applied round, and ingest publishes after applying.

**The residual, stated and tested, not hidden:** a dead curator's un-published tail (≤ one round)
is absent after failover and re-lands via re-apply — at-least-once × idempotent apply, the same
contract as everything else. The gate asserts the absence explicitly before asserting the re-land.

**Gates (green):** `curator_failover_resumes_on_a_fresh_clone_via_the_shared_remote` — the
companion litmus ("failover transfers nothing") restored for the node-local store: A publishes and
dies; B, a FRESH clone, promotes, adopts, reads A's corpus, converges with the remote, tripwire
quiet. Plus `a_curator_that_cannot_refresh_never_serves`. All git_store (24) + curator (6) +
exactly-once + control-plane suites green; clippy clean.
