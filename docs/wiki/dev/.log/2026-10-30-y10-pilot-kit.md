# 2026-10-30 — Y10, the pilot kit

Adopter-surface row Y10 delivered. The kit is [`docs/operations/pilot-kit/`](../../../operations/pilot-kit/README.md)
and the runbook `customer-pilot.md` names it.

- **The walk.** The kit's README has six steps:
  - step 0 is tutorial 7, the `one-hour` job's path, as the first checkpoint;
  - then the two-domain scaffold pointed at a checkout;
  - a call across the edge each way;
  - `doctor` on all four nodes;
  - `test --faults` over the kit's own `units/` and `faults.toml`;
  - and the report.
- **CI runs the README.** Its `bash pilot` blocks are extracted by `scripts/check-pilot-kit.py --blocks` and run as one
  script in the `Scaffold` job. The README is what runs, not a copy of it.
- **The report.** `report.py` fills `report-template.md` from the doctor text and the `--format json` faults output,
  with one section per guarantee a class exercised.
  - Rule ids in a class's `exercised` list (`ae.preflight`, `kv.propagation`, …) are left out; they are the rule
    catalogue's, not this report's.
  - A guarantee any node reports `not_verifiable_here` goes to *What no node can show*, with the doctor's own remedy
    text from a node that reports it. The federation facts read `not_applicable` on members and
    `not_verifiable_here` on gateways, so "every node" would have missed them.
- **The matrix.** `shared-responsibility-matrix.md` § *From a `doctor` line to its row* maps all 39 catalogue ids to a
  row, or to *no row* with a reason (`cons.safety_profile`: processing integrity is not a category the matrix covers).
- **The gate.** `scripts/check-pilot-kit.py`, in `make check` and the documentation CI job, holds that table complete
  in both directions and resolves each named row against the matrix's own first column. It runs `report.py` over
  `tests/fixtures/pilot-kit/`, real output captured from the scaffold and the kit's declaration.
  - **Plants:** eight clauses were each planted out, and each failed by name.
  - **The non-`doctor`-input refusal:** this one needed both of its `die` calls removed before the plant showed it,
    because either alone still refuses.
- **Kept open:** the named-deployment line on `what-is-proven.md` stays open and now says the kit is not the deployment.
