  components on aarch64, since the host compiles with Cranelift. -0378 (medium): a host panic lowering a host-created
  component-model stream of a mismatched payload type; the host's own code creates no stream.

  `wasmtime = "49"` (the shape of #476 and #625: the lock carries the fix).
- Exposure by tag, read from each tag's `Cargo.lock`: -0379 every release v2.0.0–v2.36.0 (45.0.3 → 49.0.3, no
  unaffected range); -0378 v2.4.0–v2.36.0 (46.0.2 onwards; < 46 unaffected).
