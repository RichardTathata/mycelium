# [2026-09-18] ingest | v2.8.0 released (the v3 contracts axis)

Up: [dev](../dev.md) · ledger [history](../history.md) · plan `docs/plans/v3-contracts-axis.md` rev 1.12 ·
tag `v2.8.0`.

**Why a MINOR.** Substantial new public API across eight items and three new crates, and nothing removed or
redefined. Wire **v12** (`PREV = 11`) and the on-disk format are unchanged, so the rolling upgrade holds. The
runbook's rule is that new public API is `x.Y.0` however small each addition looks; here it is not small.

**Why one tag rather than eight.** The items constrain each other: item 6's seams are what make item 4's
governors replayable, item 1's receipt vocabulary is what items 2 and 5 hand back, item 7's caller identity is
what item 2 carries across a domain edge. Tagging separately would have shipped a vocabulary before the things
that speak it.

**What shipped** is the CHANGELOG's `[2.8.0]` section — 68 accumulated entries, one per PR, left in place
under the new heading rather than rewritten. The release section above them says what the whole is.

**The upgrade notes**, all one class: a struct gained a field, so an exhaustive struct literal breaks and
nothing else does. `GossipConfig.domain_profile`; `GovernorSnapshot` (`profile`, `held_by_spacing`,
`held_by_settling`, `settled_unknown`) and `ParamSnapshot.pending`; `OpacityHint.release_spacing_ms`;
`BoardConfig.high_watermark` and `BoardStats.rejected`. This is the same class as `GossipConfig`'s additions in
2.5.0, and the `3.0.0` removal ledger already carries the entry that ends the series.

**One behavioural change stated on its own**, because it is not additive: a federated call against a
blackholed gateway now returns `DeliveryUnknown` within a bound instead of waiting indefinitely. Nobody could
have depended on the old behaviour — it was a hang — but it is a change in what the code does, not just in
what it offers.

**Gates on the bumped tree.** `make check` clean; the three library suites re-run (654 tls / 704 compliance /
480 gateway-only); the two-mesh Docker suite green at 40 checks, locally and as the CI `federation` job. Wire
constants verified identical to `v2.7.0` by diffing `framing.rs` rather than by memory.

**Versions.** Bumped to 2.8.0: root, core, agentfacts, blackboard, commitment, effects, sim, tuple-space,
wasm-host, wiki — every workspace crate that was on 2.7.0. `mycelium-reason` stays on its own track (0.6.2),
as do the SDK companions.

**What this tag knowingly does not contain**, each named in the plan rather than left to silence: the
scheduler seam's first arm (pinned by CN2's whole-node replay divergence); item 2's row 11 (SDK verbs, TLS on
the federation edge itself, a hostile network, more than two domains); V1, the nightly scale runner; the
private RA slice beyond RA0.

**Queue state after this tag.** The public axis is complete except the items above. The next substantial
public piece is the scheduler seam, whose first arm is gated by a pin that exists precisely so it cannot be
started by accident.
