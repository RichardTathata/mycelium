## [2026-10-23] ingest | mycelium init and the two templates (adopter-surface X2)

- `src/init.rs` embeds `templates/*` at compile time (`include_str!` per file, listed; the test
  `every_template_file_on_disk_is_embedded` walks the directory and compares bytes), replaces `{{MYCELIUM_TAG}}` with the
  binary's `v<version>`, and writes only into a new or empty directory. `templates/` is excluded from the workspace;
  each template's `Cargo.toml` carries an empty `[workspace]` so it is a root of its own inside the repository too.
- `governed-call` (Rust): `GossipConfig::load_from_file("node.toml")` for node A; node B derives its config
  (`bind_port + 1`, bootstrap to A, the same `[tls] auto_cert_dir` — `load_or_generate` keys each node's cert and key by
  node id, so one directory is one CA). A attaches `EvidenceJournal::open(.., Strict)`, a custom `ActionEvaluator`
  (`src/policy.rs`: `security_relevant_arguments = ["ledger"]`, permit petty-cash, deny capital, else indeterminate),
  `with_provider_enforcement()`, a `DecisionSink`; registers an MCP tool and spawns `run_capability_probes` over the
  unit file. B calls `service().rpc_call(A, "mcp.invoke", tools/call …)` twice; the provider derives
  `tools/call` + `tool:purchase.place@A` + arguments from the payload (no claim needed). The prompt skill is registered
  on B and called by A: an `llm.invoke` under provider enforcement is refused `resource_unnamed` without a claim.
- `governed-call-py`: the binary with `[[gateway_named_tokens]]` (alice: kv:read, kv:write, cap:write; reader:
  kv:read); `declare_from` (cap:write) returns `not_enforced: [mandate, rule]`; `set` permitted; the reader's `set`
  403 `insufficient_scope` (`gateway.auth`, counted not recorded). The plan's "both templates attach an evaluator" was
  wrong for Python and is corrected: no configuration attaches an evaluator to the binary.
- Found: `ReferenceEvaluator` uses the trait default `security_relevant_arguments()` (none), so `Rule::requiring_value`

  reference evaluator. Recorded in the plan's X2 text; not fixed here (the private Cedar adapter declares its own).
