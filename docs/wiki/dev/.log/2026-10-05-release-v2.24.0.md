- **In zsh an unquoted `$VAR` holding a newline-separated list is one word.** RELEASING.md §4's bump
  loop (`mapfile` + `"${TRAIN[@]}"`) is bash; under zsh the substitute `for f in $TRAIN` ran once with
  the whole list as a filename, bumped nothing, and printed a lockfile count of 0 — which the step's own
  check caught. Use `| while read -r f`.
