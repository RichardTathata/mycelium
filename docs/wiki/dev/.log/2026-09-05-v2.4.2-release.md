# 2026-09-05 — v2.4.2 released (security + durability PATCH)

Cut **v2.4.2** (tag `v2.4.2`, release PR merged to `main`). Wire **v12** (PREV 11) unchanged;
on-disk persistence format unchanged. Release gate: CI green on the three fix merges
(#169 `e83732a`, #172 `25f5c04`, #171 `9e17fcb`) and on the release PR before tagging.

**Why a patch the day after v2.4.1:** one external code review (Codex, 2026-09-05) found five
issues, all reproduced before fixing:
- **Security (finding 4):** `POST /mcp`, `GET /signals/{kind}`, `GET /consensus/{slot}` answered
  without the gateway bearer — `tools/call` invoked any cluster tool *with the node's identity*.
  Now behind the same layer as `/gateway/*` (`mcp:invoke` / `mesh:read` / `consensus:read`);
  `/bulk/{id}` stays a nonce-capability URL by design. Same shape as the v2.4.1 finding.
- **Durability (findings 1–3, all P1):** a threshold snapshot could erase an acked, fsynced write;
  replay filtered WAL records by HLC as a log position; `Ok` acks from a dead writer,
  `append_sync` not syncing outside `Flush`, consensus discarding the result. Fixed with
  apply-then-append everywhere, a WAL-tail LWW merge in `do_snapshot`, LWW replay of every record,
  `BrokenPipe` acks, forced fsync, `ConsensusResult::Committed { persisted }`.
- **Companion (finding 5, P2):** `langgraph-checkpoint-mycelium` 0.1.1 — `alist` selected rows on
  the sync client.

**Upgrade notes:** scoped-token deployments grant `mcp:invoke` / `mesh:read` / `consensus:read`
(`docs/operations/rbac.md`); a downstream exhaustive `Committed { slot, value, ballot }` destructure
adds `..`. Nothing else changes for callers.

**Not in this release:** the review's TypeScript-CI coverage note (type-check only; the jest suite
skips without a live node) — a CI-coverage item, not a defect. The CLA allowlist was fixed the same
day (`RichardTathata` added; the v2.4.2 PRs show a red CLA check from before that fix).
