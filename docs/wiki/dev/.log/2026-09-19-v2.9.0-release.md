# [2026-09-19] ingest | v2.9.0 released (the axis proving itself)

Up: [dev](../dev.md) · ledger [history](../history.md) · plan `docs/plans/v3-contracts-axis.md` rev 1.12 ·
tag `v2.9.0`.

**Why a MINOR.** New public API — `sim_seam::{pause_clock_for_replay, resume_clock_after_replay,
mono_instant}` under the `sim` feature, and `mycelium_wiki::{MandateRevoked, WikiError::mandate_revoked,
as_mandate_revoked}` — plus one behavioural change, with nothing removed. Wire **v12** and the on-disk format
unchanged, so the rolling upgrade holds. The runbook's rule is that new public API is `x.Y.0`.

**Why so soon after 2.8.0.** 2.8.0 shipped the axis; this ships the *evidence* that it holds — a whole node
replaying deterministically, and a runnable demonstration per item. The two are separate claims and deserve
separate tags: the second is the one an outside reader can check.

**What the tag contains.** The scheduler seam's first arm (CN2 now complete); §12.1's demonstration gallery
complete, with the four CLI demonstrations *run* in CI; the mandate-fence refusal fix; the federation client's
bounded attempt; and the hysteresis correction with its per-breaker plant.

**The upgrade note, in full.** A `mycelium-wiki` write refused by the mandate fence now returns
`WikiError::Io` carrying `MandateRevoked { refname, expected, found }` instead of `WikiError::Conflict`. Any
retry loop keyed on `Conflict` will stop retrying that case — which is the *purpose*: a replaced curator who
retries refuses forever. A genuine lost compare-and-swap race still returns `Conflict`, and a store with no
mandate fence configured behaves exactly as before. Carried inside the existing `Io` variant (the `GateRefusal`
shape), so no downstream `match` breaks.

**What this release is honest about.** Two of the six demonstrations found real defects, which is the argument
for §12's gallery being a gate rather than decoration — made by the gate itself rather than asserted. Three
overclaims in my own drafts were caught before shipping, each correction making the artefact weaker and
accurate: a clean shutdown called a crash; a trace said to name a record it only digests; a hysteresis gate
asserting rest where the measurement supports damping.

**Gates on the bumped tree.** `make check` clean; 654/704/480 library suites; core with and without `sim`; sim,
commitment and wiki suites; the wire back-compat gate green with the constants diffed against `v2.8.0` rather
than recalled.

**Versions.** Bumped to 2.9.0: root, core, agentfacts, blackboard, commitment, effects, sim, tuple-space,
wasm-host, wiki. `mycelium-reason` stays on its own track (0.6.2), as do the SDK companions.

**Still outstanding after this tag**, unchanged by it: the nightly scale runner (its self-hosted box is offline,
so the job queues silently — V1 has never been met); item 2's row 11; and the private RA slice, still a stub.
