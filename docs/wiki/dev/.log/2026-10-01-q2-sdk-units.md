# 2026-10-01 — Q2 answered: SDK agents load their unit files

**What:** `POST /gateway/units/declare` (`src/agent/http.rs`, scope `cap:write`), the SDK verbs
(`declare_units` / `declare_from` in Python, `declareUnits` in TypeScript, both returning a `UnitHandle`),
the gateway test `test_gateway_units_declare_one_handle_for_a_whole_unit` (seen failing first — the
route did not exist), SDK stub tests.

**Durable knowledge:**
- **The plan's premise was wrong.** Q2's candidate answer assumed requirements and groups already had
  gateway routes; only capability advertisement did. Checked against the router before building.
- **Carry text, parse once.** The SDKs post the unit file as text and the node parses it with the same
  loader `wire-check` and the stem use — the Q5 principle (no second codec to drift) applied to TOML.
- **One handle per unit.** The gateway's handle table entry gained a `_held` box; a unit's capability
  registrations, requirement and group handles live in it, so the existing delete and heartbeat routes
  work unchanged and a missed lease retracts the whole unit. The lease watchdog is now one function.
