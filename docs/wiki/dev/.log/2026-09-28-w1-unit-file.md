`CapFilter::matches` and not a re-implementation.

**Durable knowledge:**
- **A Version is written `{ version = "2.1.0" }`**; a bare string stays `Text`. The plan's §3 example
  had said a bare `"2.1.0"` parses to a Version — that would have changed the meaning of every existing
  file's string attributes, so the explicit form won (D3 refinement recorded on the plan).
- `TomlCapValue` is `#[serde(untagged)]` and **variant order is load-bearing**: `Version { version }`
  must precede the scalars and `Bool` must precede `Integer`. A constraint is `Bare(value) | Op(table)`;
  the two are told apart by shape and an operator table must name exactly one known operator.
- The kinds a `[hosts]` table may name are `HOSTABLE_KINDS = ["wasm-component", "blob"]` — strings,
  because `mycelium` does not depend on the wasm-host crate that owns `ArtifactKind`; keep the two lists
  equal by hand until a test in the wasm-host crate pins them.
- Nothing is declared to the mesh from the file at startup yet (D18 / R1's runtime half); the pin
  `existing_capability_files_load_unchanged` is the promise that adding sections moved nothing.
